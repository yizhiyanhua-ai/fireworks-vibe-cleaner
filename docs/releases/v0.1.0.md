# v0.1.0 release notes

Local acceptance completed on 2026-09-21. Remote CI, release assets and public-tag installation are verified separately in the published GitHub Release record. Live Jev inference remains unverified.

## Included

A standalone Python CLI and portable Agent Skill for Codex/Claude Code storage inspection, approved quarantine of narrowly recognized old logs and rebuildable bytecode, restoration, separate permanent purge, selected byte-verified backups, and optional metadata-only Jev advice. English and Chinese READMEs describe the same boundaries.

## Limits

- Session source deletion and harness resume verification are disabled/unverified.
- Worktrees and unique assets are retained; no automatic Git worktree removal.
- Quarantine is same-volume and releases zero bytes; backups retain originals and consume storage.
- Cross-volume moves and encrypted backups are unavailable.
- `lsof` plus an operator acknowledgement of stopped writers is required for cleanup mutations; it is not proof against every concurrent writer.
- Jev availability, prediction quality and provider latency are not established by mock tests. Core cleanup remains usable without it.
- No real-user space-saving quantity is claimed by this release.
