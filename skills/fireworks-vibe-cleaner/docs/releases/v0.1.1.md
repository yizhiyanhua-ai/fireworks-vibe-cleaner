# v0.1.1 — Real-data validation and log protection fix

The real local scan found a safety issue in v0.1.0: arbitrary service logs under Codex log directories could become cleanup candidates. This patch only admits the exact `codex-tui.log` basename directly under `log/` or `logs/`. Execution revalidates existing plans against the tightened policy. Upgrade before executing old cleanup plans.
